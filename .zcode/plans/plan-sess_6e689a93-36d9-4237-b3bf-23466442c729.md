# Remove Co-founder + Unify Logo/Favicons

## Context
Two changes: (1) **Vijeesh Vijayan ("Co-founder & Director, Education")** must be scrubbed from the site — only Minhaj Al Shukoor ("Founder & CEO") remains. (2) The brand mark (black rounded square, white "R ✈ A", periwinkle plane) currently exists in 3 unmaintained variants — font-dependent `public/favicon.svg`, a raster `apple-touch-icon.png`, and the inline `Logo.astro` lockup — with no `.ico` fallback, no web manifest, and no PNG icons. We'll make one path-based SVG the single source and generate every other icon artifact from it.

User decisions: blog posts re-assign to **Minhaj**; OG share photos stay **unbranded**.

   - Keep generic "founder-led" copy (still true) and Minhaj's quote.
3. **Blog bylines** — `author: 'vijeesh'` → `'minhaj'` in `src/content/blog/mbbs-in-china-5-things-to-know.md` and `top-5-historical-sites-beijing.md` (L5).

## Task B — One logo, everywhere

1. **Rewrite `public/favicon.svg`** as the canonical, **path-based** master: R and A letterforms as vector paths (no `<text>`/font dependency — hand-authored geometric paths matching the current Helvetica-ish design), same periwinkle plane and black rx-8 tile. This is the single brand artifact; no duplicate logo.svg.
2. **New `scripts/generate-icons.mjs`** using `sharp` (already a devDependency) to render from `public/favicon.svg`:
   - `apple-touch-icon.png` — 180×180, flattened opaque background (fixes transparent-corner alpha issue)
   - `icon-192.png`, `icon-512.png` (any) + `icon-512-maskable.png` (logo at ~80% in safe zone)
   - `favicon-32.png` fallback
   - `favicon.ico` — tiny hand-rolled ICO packer embedding the 32px PNG (valid PNG-in-ICO format; no new dependency)
   - npm script: `"icons:generate"`. Commit the generated outputs (public/ files are static).
3. **New `public/site.webmanifest`** — name/short_name, icons (192, 512, maskable 512), `theme_color`/`background_color` `#0a0a0a`, `start_url` `/`, `display: "browser"` (no service worker — not a PWA).
4. **`src/layouts/BaseLayout.astro`** head (L76–78): keep the SVG icon link, add `favicon-32.png` + `favicon.ico` fallback links and `<link rel="manifest" href="/site.webmanifest" />`. Keep apple-touch-icon.
5. **`src/lib/schema.ts`** L17 + L249: JSON-LD `logo: \`${SITE.url}/favicon.svg\`` → `logo: \`${SITE.url}/icon-512.png\`` (Google's Organization-logo guidance prefers raster ≥112×112).
6. **`netlify.toml`**: extend the headers block with long-lived `Cache-Control` for `/favicon*`, `/icon-*`, `/apple-touch-icon.png` (manifest gets short/no cache). Optional but cheap.
7. Header/footer already render the theme-aware `Logo.astro` lockup — unchanged; the new icon artwork matches it.
